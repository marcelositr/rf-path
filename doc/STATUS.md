# RF-Path — Project Status

## Current phase

**Phase 4 — RF model**

## Current state

The Rust foundation, geometry/RF primitives, and SRTM terrain layer are implemented and validated. The project now has a mmap-backed SRTM3 HGT reader with explicit tile selection, big-endian decoding, north-to-south row handling, bilinear interpolation, explicit NoData errors, and an in-memory tile cache.

Deterministic synthetic HGT fixtures are generated by integration tests at runtime; real SRTM data is not committed to the repository. The development-only Python reference layer contains corresponding geographic, RF, and SRTM tile/interpolation calculations.

- CLI parsing is currently a structural foundation; full command execution remains pending.
