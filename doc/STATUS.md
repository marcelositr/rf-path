# RF-Path — Project Status

## Current phase

**Phase 3 — SRTM terrain**

## Current state

The Rust foundation and initial geometry/RF primitives are implemented. The project now has a mmap-backed SRTM3 HGT reader with explicit tile selection, big-endian decoding, north-to-south row handling, bilinear interpolation, NoData errors, and an in-memory tile cache.

Deterministic synthetic HGT fixtures are generated by integration tests at runtime; real SRTM data is not committed to the repository. The development-only Python reference layer now contains corresponding geographic, RF, and SRTM tile/interpolation calculations.
